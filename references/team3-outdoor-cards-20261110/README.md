# 3팀 실외기실 설비이력카드

2026-11-10에 제공된 ZIP에서 `3팀/실외기실`의 14카드만 선별했다. 카드 번호는 072~076, 084~092이며 077~083의 배합실 자료는 포함하지 않았다.

원본 44파일(카드 JSON 14개·HTML 14개·합성사진 14장·PPTX 첨부 2개)은 `source/3팀/실외기실/`에 바이트 그대로 보존한다. `source-manifest.json`은 각 원본의 ZIP 멤버·상대 경로·크기·SHA256을 기록한다. `cards.json`은 원본 카드 메타에 출처 경로와 ZIP 번호만 덧붙인 파생 목록이다.

앱용 합성사진 14장과 4방향 분리 사진 56장은 `apps/site/photos/team3-outdoor-cards/`에 준비했다. `photo-manifest.json`에 사진 원본·자산 경로·패널 좌표·SHA256을 기록했다. 합성사진은 바이트 그대로 복사하고, 방향별 사진만 네 개의 같은 폭 패널로 잘라 JPEG로 저장했다. 카드 촬영 방향은 도면의 방위나 모델 축과 자동으로 대응하지 않는다.

제조사·모델명·제조일·상세사양은 모두 공란이며 개별 설치 좌표·실측 치수는 제공되지 않았다. 저장된 비가동중/가동률 0을 현재 실시간 상태로 취급하지 않는다. 089/090의 표시명은 40RT이지만 사진명·장비 코드·원본 경로에 60RT 표기가 남아 있어 양쪽을 보존했다. 세부 목록과 한계는 `metadata-summary.json`을 따른다.

086과 089에 들어 있는 이코노마이저 설치 공사 PPTX 두 파일은 동일 SHA256의 중복 첨부다. 원본 두 파일 모두 보존했다.

연락표는 `tmp/team3-outdoor-cards-20261110/contact-all.jpg`와 번호 구간별 연락표 4장에 있다. 추출 과정에서 ZIP SHA256 및 기존 2팀 원본 127파일의 SHA256이 기존 보존 목록과 같은지 확인했다. 이 자료 준비 단계에서는 실외기 모델·좌표·설비 대응을 수정하지 않았다.

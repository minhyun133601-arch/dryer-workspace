# 희창유업 3D 모델링 작업실

공장·건조실·설비 모델을 수정하고 도면을 검토하는 로컬 프로젝트입니다. 시작 화면에서 **희창유업 3D**, **도면 근거자료**, **발표용**을 엽니다.

## 실행

**[프로젝트 실행.cmd](프로젝트%20실행.cmd)**를 더블클릭하거나 프로젝트 폴더에서 실행합니다. Node.js 20 이상이 필요하며 도면 검토는 Python 3을 사용합니다.

```powershell
npm start
```

기본 주소는 `http://127.0.0.1:4173`입니다. 서버만 실행할 때는 `npm run serve`, 종료할 때는 실행 창에서 `Ctrl+C`를 누릅니다.

건조기 시연은 **발표용 → 시연 시작**을 누릅니다. 회사 로고를 단 안내자와 함께 1층·1.5층·3~7층, 옥상과 엘리베이터 기계실을 사람 눈높이로 걸으며 살펴본 뒤 버너 조립·분해로 마칩니다. 기본 경로는 3분 56초로 약 4분입니다. 배속은 0.5·1·1.5·2·3배로 바꿀 수 있고, 끝나면 건조기 층별 평면·입체를 직접 회전·확대해 확인합니다. 재생·일시정지 중에는 다른 메뉴로 이동하지 않으며, 창을 숨기면 일시정지합니다. 처음부터 버튼으로 시연을 준비 상태로 돌릴 수 있습니다.

발표에서는 걷는 동안 앞의 문이 자연스럽게 열리고, 한 번 열린 문은 열린 상태를 유지합니다. 별도의 문 조작 없이 이동 흐름을 따라가면 됩니다. 1층→1.5층→3층과 6층→7층은 실제 계단을 오르며, 1.5층에서는 탈의실에서 직진해 관찰 통로와 OP실을 지나 끝의 계단으로 3층에 올라갑니다.

### 모터·제어판·열교환기를 나중에 추가할 때

바탕화면의 `후속작업_모터·제어판·열교환기_20261110` 작업실에서 필요한 기능의 단독 HTML을 아래 위치에 `index.html`로 복사합니다. `npm start`로 연 시작 화면을 새로 고치면 해당 메뉴가 나타납니다.

| 기능 | 후속 작업실의 단독 파일 | 현재 프로젝트에 넣을 위치 |
| --- | --- | --- |
| 모터 분해도 | `exports/motor.html` | `apps/motor/index.html` |
| 제어판 | `exports/건조기-제어판.html` | `apps/panel/index.html` |
| 열교환기 시뮬레이터 | `exports/건조기-열교환기-시뮬레이터.html` | `apps/heat-exchanger/index.html` |

제어판 단독 파일이 필요하면 후속 작업실에서 `npm run export:panel`로 생성합니다.

## 도면·현장영상 별도 보관

큰 원본 자료는 프로젝트와 같은 바탕화면의 별도 폴더에 둡니다. 도면 메뉴는 기존처럼 열며, 도면 앱의 작은 실행 소스는 `tooling/drawing-review/`에서 관리합니다. 검토 의견·사용후보 표시와 변환 도구도 도면 보관 폴더에 함께 둡니다.

| 보관 폴더 | 내용 |
| --- | --- |
| `../프로젝트_도면자료/건물3D 후보도면/` | 도면 원본과 목록 |
| `../프로젝트_도면자료/미리보기캐시/` | 준비된 도면 미리보기 |
| `../프로젝트_도면자료/검토기록/` | 기존 검토 의견·사용후보 DB와 기록 |
| `../프로젝트_도면자료/변환도구/` | 필요할 때 사용하는 도면 변환 도구 |
| `../프로젝트_현장영상_보관/1층 보완 조제실 시작/` | 1층 보완 MP4 2개와 촬영정보 TXT 2개 |

[도면 저장 경로 설정](docs/drawing-storage.json)은 프로젝트 폴더 기준 상대경로입니다. 자료를 다른 곳으로 옮기면 이 파일을 고친 뒤 프로젝트를 다시 실행하세요. `DRAWING_REVIEW_ROOT`·`DRAWING_REVIEW_CACHE`·`DRAWING_REVIEW_DATA`·`DRAWING_REVIEW_TOOLS` 환경변수로도 지정할 수 있습니다. 다른 PC로 옮길 때는 프로젝트와 보관 폴더를 함께 복사해야 도면과 검토 기록을 계속 열 수 있습니다. 3D·발표 공유 HTML은 원본 도면 폴더 없이도 열립니다.

현재 화면에서 사용하는 사진·로고와 1층 근거 JPEG 12장은 유지합니다. 임시 검토 JPEG와 디코딩 PNG 100장은 정리했으며 원본 영상에서 다시 추출할 수 있습니다. 이동·삭제 목록과 SHA256 검증은 [자료 정리 기록](docs/material-storage-20261113.json)에 남깁니다. 도면 분리는 프로젝트 복사·백업 용량을 줄이며, 이미 도면을 별도로 불러오는 발표 화면의 로딩에는 거의 영향을 주지 않습니다.

루트의 `회사로고.jpg`는 앱 로고와 동일한 중복 파일이어서 정리했습니다. 실제 로고는 `apps/site/assets/branding/company-logo.jpg` 한 곳에서 사용합니다. 남아 있던 도면 앱의 프로그램 소스·기록·도구를 정리한 내역은 [추가 정리 기록](docs/material-cleanup-followup-20261113.json)에 있습니다.

## 검사와 공유본 생성

```powershell
npm run check
npm test
npm run export:share
npm run export:presentation
```

`export:share`는 전체 공유본 `exports/건조기-통합-공유.html`, `export:presentation`은 건조실 발표본 `exports/건조실-발표용.html`을 만듭니다. 소스를 수정한 뒤 공유본도 다시 생성해야 반영됩니다.

발표 화면의 `도면·직접 보기`에서 시연 전이나 진행 중에도 층별 평면·입체를 볼 수 있습니다. 도면을 열면 시연이 멈추고 `시연 이어보기`로 같은 지점부터 재생합니다. 전체 화면에서는 메뉴와 재생 도구를 숨기고 장면을 화면에 꽉 채웁니다. 준비 상태에서 전체 화면을 열면 시연이 시작되며, `Space`로 재생·일시정지, `D`로 현재 층 도면 보기·시연 이어보기, `Esc`로 전체 화면을 종료합니다.

## 저장 배치

브라우저에서 옮긴 배치는 해당 브라우저의 `localStorage`에 저장됩니다. 기본 위치를 고쳐도 저장 배치가 화면에 우선 적용될 수 있습니다. 문제가 보이면 사용 중인 브라우저·주소의 저장 배치를 먼저 확인하고, 설비 ID나 저장 키를 임의로 바꾸지 않습니다.

이전 자료 정리 작업의 보관 경로와 이동 기록은 [과거 보관 위치 안내](docs/archived-materials.json)에 남아 있습니다. 이번 도면·현장영상 분리 보관은 위의 저장 경로 설정과 자료 정리 기록을 기준으로 확인합니다.

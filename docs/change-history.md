# 2026-11-12까지의 모델링·정리 기록

**11/12 조제실→외포장실 출입구·균질기 펌프(스크린샷 262):** 조제실에서 외포장실로 가는 문을 원료계량창고 쪽이 아니라 스크린샷이 바라보는 서쪽 벽 남쪽 끝(균질기 옆)으로 옮겼습니다. 촬영된 배치도의 서쪽 출입구도 이 한 곳뿐이라 옛 도면의 원료계량창고·탱크 뒤 개구부는 막았고, 문 너머 서쪽 홀은 **외포장실**로 표시합니다. 균질기는 문 앞을 비우도록 옮기고 앞면을 조제실 쪽으로 돌렸으며, 2.5m 떨어져 통로에 있던 이송 펌프는 균질기 바로 뒤에 붙여 토출관을 연결했습니다. 사용자 Edge 저장 배치도 한 번만 새 위치로 옮기고 직접 옮긴 위치는 유지합니다. [근거·검증 기록](../references/preparation-room-20261111/outer-pack-door-20261112.json).

**11/12 출입문 부착물·장애물 보정:** 영상·도면과 실제 모델의 벽면, 개구부, 문짝 회전·보행 공간을 대조했습니다. 관통하던 차양·셔터 하우징·표지판·실내기와 떠 있던 제어함·실외기 받침을 정리하고 고정판·브래킷을 연결했습니다. 조제실 고속문 앞 IBC·팔레트와 화장실 문 옆 소품, 후면 노란 문 앞 보온배관·외함을 옆으로 조정하고 보일러실 반입 셔터 앞 배관을 상부로 우회했습니다. 열린 셔터의 하우징 수납과 접근 공간을 기하 검사했습니다. 변경 간격·배관 우회는 모델 비례 보정이며 실측 확정값으로 표시하지 않습니다. 근거·검증 기록은 `references/door-mount-clearance-20261112/`에 보관합니다.

**11/12 사람 이동·출입·시야 보정:** 기본/Shift 이동을 4/8m/s에서 6/12m/s로 1.5배 높이고, 빠른 이동에서도 좁은 계단을 건너뛰지 않도록 이동거리를 세분화했습니다. 내부로 들어갈 수 있는 문만 작동하며 **자동 문열기**는 기본 해제입니다. 문 앞에서 **F 또는 화면 버튼**으로 여닫고, 체크하면 접근·이탈에 따라 자동 개폐합니다. 2팀 뒷문과 1층 실내를 양방향으로 연결했습니다. 사람 눈높이 1.65m, 기본 세로 시야각 70°와 **시야 배율 75~125%**를 적용했습니다. 속도는 탐색용이며 도면으로 확인한 건물·층·문 치수는 미터 기준을 유지합니다. 캠퍼스 물류장 외곽, 액상 천장높이와 개별 설비 실측이 미확정인 부분은 근사로 남깁니다. 아래 과거 자동 개폐 기록은 이번 선택 방식으로 갱신했습니다. [도면·보행 배율 검토](../references/walking-realism-20261112/scale-audit.json).

**11/12 폐수처리장:** 사용자 지정인 경비실 옆 기존10동 자리에 2022.3.9 계통도·평면·측면도 기반 시설을 추가했습니다. 폭기조1~4, 침전·유량조정·반응·약품·슬러지·탈수설비와 공정 연결을 재현하고, 선택 시 덮개와 지붕을 열어 지하 수조를 표시합니다. 시설 이동·회전 시 실제 지면 개구부가 따라가고 원래 지면은 복구됩니다. 도면3장을 근거 패널에 등록하고 전체 공유 HTML도 갱신했습니다. 기존 건물·경비실·정문 차로 좌표와 건조실 발표본 범위는 유지합니다. [배치 근거와 근사 범위](../references/wastewater-20261112/reconstruction.json).

**11/12 근거 자료 정리:** 참고 사진·영상, 검토용 출력물과 2팀 설비이력카드 파일 8,957개(약 9.62GB)를 바탕화면 `삭제 예정/프로젝트_자료정리_20261112/`로 옮겼습니다. 필요한 도면과 도면 검토 기능, 3팀 카드 66건의 원본·첨부 200파일과 통합 PDF는 유지합니다. 3D 화면과 공유 파일은 도면·3팀 카드만 표시합니다. 이전 기록에 적힌 이동 전 경로는 [이동 목록](../workspace/cleanup-20261112/move-plan.json)으로 추적할 수 있습니다. 영구 삭제는 하지 않았습니다.

**11/12 문 자동 개폐:** 통행문과 출입 셔터는 닫힌 상태로 시작하며, 사람이 양쪽에서 가까이 가면 부드럽게 열립니다. 멀어지면 잠시 기다린 뒤 닫히고, 문 근처에서는 열린 상태를 유지합니다. 층 높이와 문틀의 이동·회전을 반영하며 고속·롤러 셔터는 상부 커버 안으로 접힙니다. 자동 개폐는 3D 탐색 동작입니다.

**11/12 사람 이동·탱크 복원:** 모든 공간에서 벽 통과를 허용하며 보행 속도를 낮추고 바닥·계단·작업발판 높이를 따라 이동하도록 보완했습니다. 계단의 높이 변화는 눈높이에 부드럽게 반영합니다. 조제실 혼합·살균 탱크 1 복원은 저장값이 정확히 `[-7, -8]`일 때만 동작해 실제 브라우저에는 적용되지 않았습니다(아래 후속 보정). [첫 복원 기록](../references/preparation-room-20261111/missing-tank-restoration-20261112.json).

**11/12 조제실 빈 탱크 자리 채움(스크린샷 261):** 호모 믹스-2와 카제인 탱크 사이의 빈 원형 구멍은 **호모 믹스-1(혼합·살균 탱크 1)** 자리입니다. 사용자 Edge 저장 배치를 직접 확인해 보니 이 탱크가 조제실 밖 `[-7.25, -8]`에 남아 있었습니다. 이제 이전 개정에서 작업발판 밖에 저장된 매달린 탱크는 좌표값과 관계없이 한 번 제자리 구멍으로 돌아옵니다. 저장 배치는 0.25 격자에 맞춰지는데, 이때 탱크가 구멍 중심에서 0.15~0.25m 어긋나 한쪽에 아래층이 비치던 문제도 고쳤습니다. 작업발판·탱크·하부 공통 배관·조작반 기본 좌표를 격자 위에 두고, 구멍 위치는 탱크 좌표에서 계산합니다. 발판 위에서의 수동 이동, 이번 개정 이후 저장, 명시적으로 불러온 배치는 그대로 둡니다. [실제 저장값·보정·검증 기록](../references/preparation-room-20261111/tank-opening-alignment-20261112.json).

**11/11 영상 재검토 보정:** 영상 4개(조제실, 보일러실 2개, 건물 뒤편)를 1초 간격으로 전부 확인하고 GPS와 항공사진을 겹쳐 대조해 다음을 고쳤습니다. 자세한 근거는 [보일러실·주변 재검토 기록](../references/boiler-room-20261111/README.md#1111-2차-재검토--실내-배치문-겹침공무작업장엘리베이터)에 있습니다.
- **보일러실 내부:** 13.5×14m로 넓혔습니다. 측면 도로 벽에는 모서리 쪽부터 출입문(타일 테두리 천공 철문) → 회색 장비 반입 셔터 → 창 → 가스 인입관이 있습니다. 셔터 안쪽 통로를 동양 보일러(연관식 DBHI-SS 300형, 3,000kg/h, 명판 판독) 버너와 제어반이 마주합니다. 관류형 1.5ton/h, 노란 송풍기, 증기 헤더, 수평·세로 탱크, 녹색 인라인 펌프 2대, 연수기·소금, 안쪽 콘크리트 계단과 계단 밑 다단 펌프, 끝벽 가스 미터·청색 펌프 3대, 피라미드형 유리 채광 지붕을 영상 위치에 놓았습니다.
- **문 겹침:** 지대가온실 차양이 주황 원료출입구 차양과 1.5m 겹쳤고, 경광등 제어함이 고속문 안에 박혀 있었고, 보일러실 문과 회색 셔터가 겹쳤습니다. 모두 영상 순서대로 떼어 놓았습니다. 저층동 측면의 긴 띠창이 문·셔터·보일러실 벽을 가로지르던 것도 문이 없는 벽에만 작은 창으로 바꿨습니다. 조제실 화장실 이름표가 두 번 겹쳐 찍히던 것도 하나로 정리했습니다.
- **공무작업장·LPG:** LPG 용기 2기는 공무작업장 건물 서쪽 벽에 붙어 있습니다. 도로 쪽으로 4.5m 튀어나와 있던 것을 벽 앞으로 들였습니다. 공무작업장 문은 LPG 모서리를 돌자마자 나오는 도로 쪽 면 서쪽 끝, 두꺼운 콘크리트 차양 아래로 옮겼습니다. 문은 회색 양개 철문으로, 왼쪽은 닫힘(무재해·공무작업장 표찰), 오른쪽은 열림입니다. 옥상에서 도로를 건너 건조실로 가는 **배관 다리**를 추가했습니다.
- **탱크 구역 빈 곳:** 방류벽 위 연결함(캠록 6개)과 세로 주입관 표찰(야경유 2·저감미당 1·팜유 1·저감미당 2·팜유 2·저감미당 3), 야경유 1 호스함, 세척도구·공구 함, 줄무늬 기둥, 바퀴 세척조를 놓았습니다. 계단 옆 주차장에는 11/11 영상의 승용차 2대와 보호기둥·사다리를 채웠습니다. 차량은 날마다 바뀔 수 있습니다.
- **화면 전환 후 깨짐:** 다른 메뉴로 갔다 오면 3D가 크기 0으로 숨겨져 카메라 비율이 틀어질 수 있었습니다. 이제 마지막 크기를 유지합니다. 탭을 오래 비우거나 절전한 뒤 그래픽(WebGL) 연결이 끊기면 자동 복구 후 다시 그리고, 필요하면 강제 복구합니다.
- **조제실 탱크:** 작업발판의 탱크 관통 구멍이 탱크보다 커서 아래층 바닥이 링 모양으로 비쳐 '뻥 뚫려' 보였습니다. 영상(3:09~4:53, 6:00~7:30)대로 구멍을 탱크에 맞추고 테두리 띠를 둘렀습니다. 탱크는 바닥 다리 없이 발판 위 삼각 받침 브래킷 4개로 걸리고, 접시형 바닥이 약 1m 높이에 떠 있습니다. 바닥 배출구에는 밸브와 배수관을 달고 낮은 배관으로 이었습니다. 몸통 명판 '호모 믹스-1·2'를 붙였고, 지게차는 원료창고가 아니라 내부 고속셔터 안쪽 조제실 홀로 옮겼습니다.
- **엘리베이터:** 건조실 1~5층 도면 ELEV 승강로를 반투명 파란 승강로, 닫힌 스테인리스 승강장 문, 파란 **엘리베이터** 표지판으로 표시합니다. 내부 카·로프는 만들지 않았습니다.
- **휴게실 이름:** 뒤편 유리문은 영상 문패가 '생산 2팀 휴게실'이어도 실제 사용 부서인 **1팀 2파트 휴게실**로 표시합니다.

**내부 보기 보조 메뉴:** 공장 전경·건조실·스틱·소포장·액상·실외기실은 메인 공간 탭으로 유지합니다. 공장 전경에서는 그 아래 기존 상세 보기 줄에 **보일러실 내부·탱크 밸브실 내부** 버튼을 표시합니다. 건조실의 **엘리베이터실 내부·옥상 상부 현장 사진**과 같은 보조 메뉴 형식입니다. 보일러실과 밸브실은 촬영된 플랜지·체결 볼트·계기·모터 방열핀·공기관·제어부 등을 더 세세하게 보강했습니다.

**11/11 보일러실·공무환경팀실·전기실 보강:** `보일러실, 추가 파일/`의 두 영상을 대조해 건조실 저층동 옆 **1팀 2파트 보일러실**을 추가했습니다. 전경 목록이나 건물에서 보일러실을 누르면 벽·지붕을 열어 문패 기준 **3ton/h 노통연관 1대·1.5ton/h 관류형 1대**, 제어반·버너·배관·펌프·채광 지붕을 봅니다. 기존 3팀 액상 보일러 카드와 별도 공간입니다. **공무작업장·공무환경팀실은 도로 맞은편 LPG 가스 옆 건물**로 표시하고 출입구·차양·옥상 전기 가대를 보강했습니다. 옆 **수변전실(전기실)**은 녹색 철문·표지·콘크리트 출입 구조를 표현했습니다. 탱크 계단은 사용자 지시대로 **옆쪽 벽에 걸쳐진 방향**으로 옮겼고, 지대가온실·주황 고속문·회색 셔터·노란 가스관·외부 세척조·보온 배관도 새 영상에 맞췄습니다. 실 위치와 치수는 영상·동선에 따른 근사이며 전기실의 촬영되지 않은 내부는 만들지 않았습니다. [새 영상 근거와 적용 내용](../references/boiler-room-20261111/README.md).

`바탕화면/프로젝트`는 공장·설비의 3D 모델링 작업실입니다. 현장 영상·사진·도면을 근거로 공간과 설비의 외형·배치를 보완하며, 현재 메뉴는 **희창유업 3D**와 **도면 근거자료** 두 개입니다. 버너 분해도는 건조실 버너를, 냉동기 분해도는 실외기실의 해당 냉동기를 선택한 위치에서 엽니다.

상단 **도면 근거자료**에서는 준비된 도면·사진 **444개**를 **한눈에 보기**로 확인하고, **이전·다음 / ←·→**로 하나씩 넘기며 논의합니다. 확대·이동과 **90° 회전 / R**을 지원하며, **사용 후보** 표시와 검토 상태·위치 핀·의견을 저장하고 회의기록을 **CSV**로 내려받을 수 있습니다. 전체 자료 **758개**는 목록에서 확인합니다. 원본과 기존 자료는 `근거 자료/건물3D 후보도면/`, 미리보기와 검토기록은 `근거 자료/도면검토앱/`에 보관합니다. 미리보기는 검토용 이미지이며, 미리보기가 없는 자료도 원본으로 확인할 수 있습니다. 원본을 보존하고 앱을 열 때 자동 일괄 변환은 실행하지 않습니다.

2026-11-10 평면 이송 라인 보강: 현재 2팀 1층에 17구간, 2층에 11구간의 고정 롤러·컨베이어 라인을 추가했습니다. 1층의 합류 위치와 전면 연장, 2층 검사열 9대의 세로 방향을 도면에 맞췄습니다. 3층에는 근거가 없는 생산 롤러 라인을 추가하지 않았습니다. 폭·높이·좌표는 실측값이 아닌 비례 재현값이며, 상세 근거는 `references/team2-equipment-cards-20261110/transport-update.json`과 `이송라인_보강근거.txt`에 기록했습니다.

## 실행

**프로젝트 실행.cmd를 더블클릭하세요.** Node.js 20 이상이 필요하며 별도 패키지 설치나 빌드는 필요 없습니다. 도면 검토에는 Python 3도 사용합니다.

터미널에서는 다음 명령으로 실행합니다.

~~~powershell
npm start
~~~

로컬 서버와 브라우저가 열리며 도면 검토 서버도 자동으로 시작됩니다. 이미 같은 작업실이 실행 중이면 해당 화면을 다시 열고, 기본 포트가 사용 중이면 가능한 포트를 자동 선택합니다. 종료는 실행 창에서 Ctrl+C를 누릅니다. 서버만 열려면 npm run serve를 사용합니다. index.html을 파일로 직접 열면 공통 실행 CMD 안내를 표시합니다.

메뉴를 오가도 이미 연 화면과 3D 시점·선택은 유지합니다. 새로고침·종료 시 일시 상태는 초기화하며, 저장한 설비 배치와 도면 검토기록은 각 기능의 기존 저장 방식을 사용합니다. 브라우저 저장값은 같은 브라우저·프로토콜·호스트·포트 안에서 공유됩니다.

## 별도 보류한 기능

모터 분해도·제어판·열교환기 시뮬레이터의 소스와 전용 자료는 바탕화면의 **후속작업_모터·제어판·열교환기_20261110** 폴더에 원래 상대 경로를 유지해 분리했습니다. 이 폴더의 실행 안내로 후속 작업을 재개하며, 현재 작업실의 메뉴·공유 HTML에는 포함하지 않습니다. 예전 모터·제어판·열교환기 메뉴 주소는 현재 작업실의 전체 보기로 돌아갑니다.

이번 메뉴·공유 흐름 변경 전 원본은 .backups/module-separation-20261110/에 원래 상대 경로로 보존했습니다. 기존 브라우저의 제어판 편집 저장값을 지우거나 현재 모델의 배치 저장 키를 바꾸지 않습니다.

## 내보내기와 공유

### 2026-11-11 조제실·1층 보강

후속 보정에서는 1팀 2파트 현관을 바라보는 방향을 기준으로 소독실·에어샤워를 현관과 일렬로 맞추고, 화장실을 현관 옆 북향 복도의 서쪽 문으로 옮겼습니다. 소독 준비실의 캐비닛·작업대, 두 원통 싱크, 유리문·천공문·문틀·손잡이를 다시 표현했습니다. **칸막이 전체** 옵션으로 벽 전체 높이를 켜거나 내부 컷어웨이로 돌아갈 수 있고 문틀·문짝은 기본 입체 화면에서도 보입니다.

**건물 뒤편 · 2팀 출입구** 보조 메뉴는 새 뒤편 영상의 계단 현관·실외기 가대로 연결됩니다. 고층 및 낮은 계단 매스, 별개의 부자재 셔터 두 곳, 1팀 2파트 휴게실 단일 유리문(영상 문패는 옛 생산 2팀 표기), 닫힌 스테인리스 설비함과 보온관을 보강했습니다. 옹벽 쪽 실외기는 상부4·지상7·벽걸이2의 직접 확인되는 최소 수량이며 액상동 실외기실과 별도입니다. [뒤편 영상 대조 기록](../references/rear-stair-20261111/README.md)과 [소독 구역 재검토](../references/preparation-room-20261111/sanitation-evidence.json)에 근거와 미실측 항목을 남겼습니다.

공장 전경의 메인 탭 아래 **조제실 · 1층 내부**에서 들어갑니다. 원료 출입구와 별도 내부 고속셔터, 일일원료 보관·계량 구획, 넓은 조제실, 사무실·CIP 설비실, 에어샤워·위생전실, 현관 옆 화장실과 1팀 2파트 출입구를 연속 영상으로 대조했습니다. 바닥 실명도 현재 관찰에 맞춰 재해석했으며 LPG 옆 공무작업장을 내부 방으로 중복 표시하지 않습니다.

서측 탱크 5기와 S-1 리턴 1기를 구분하고 북측 제어반·서측 탱크·남측 리턴이 연결되는 작업대, 계단, 하부 균질기·펌프·배관을 보강했습니다. 1층 사람 원위치는 인원 출입구 안쪽입니다. 실제 뚜껑 명칭과 촬영된 배치도의 공정 명칭은 구분하며 실측되지 않은 벽·장비 치수는 개략입니다. 근거는 [조제실 검토 기록](../references/preparation-room-20261111/README.md), 주요 데이터는 `apps/site/preparation-data.js`입니다.

일반 실행은 루트의 **프로젝트 실행.cmd 하나**, 휴대용 공유 파일은 **exports/건조기-통합-공유.html 하나**를 사용합니다.

~~~powershell
npm run export:share
~~~

공유 파일에는 현장 3D 모델만 포함합니다. 메인과 3D 지도 사이를 오가며, 기존 ?viewer=site와 #/site 주소, 파일 저장, 설비 배치 편집, 오프라인 실행을 유지합니다. 도면 검토의 원본 파일·서버·검토 DB는 로컬 작업실에서 사용하며 휴대용 HTML에는 넣지 않습니다. 현장 지도만 별도로 내보내려면 npm run export:site를 사용합니다.

hosted 파일이 필요한 경우 node tooling/export-share.mjs --hosted <절대 출력 폴더>로 모델 뷰어와 오프라인 ZIP을 분리 생성합니다. 이 명령은 파일 생성이며 온라인 게시를 실행하지 않습니다. 기존 온라인 주소 https://dryer-map-share-20261030.kjs1335.chatgpt.site 의 게시본은 이번 로컬 분리로 자동 변경되지 않습니다.

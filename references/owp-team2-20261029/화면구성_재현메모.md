## 화면 크기와 표시 시점

- 기준 좌표 폭은 **1920px**이다. 아래 좌표는 모두 이 기준이며 `left, top` 순서다.
- 마운트 시 `innerWidth = window.innerWidth`, `zoomRatio = innerWidth / 1920 * 100`을 계산한다. 영상 컨테이너 폭은 `innerWidth`이고 `.Light` 오버레이에는 CSS `zoom: zoomRatio%`를 적용한다.
- 오버레이는 영상 위 `position: absolute; top: 0; left: 0`이다. CSS의 `.Light div` 역시 절대 좌표를 사용한다. 원본 영상의 실제 높이·해상도는 영상 메타데이터를 기준으로 확인한다.
- 보관된 다섯 화면 영상과 주 이미지의 해상도는 모두 **1920×1080**이다. `images/team2.png`, `floor1.png`, `floor3.png`, `floor4.png`, `floor5-7.png`는 각각 위 표에 연결된 영상의 6초 프레임과 픽셀 단위로 일치함을 확인했다. 이 이미지는 영상 배경 이미지이며 전체 UI 캡처가 아니다.
- 선택된 화면은 영상 0초에서 재생한다. 선택 해제 시 0초로 이동하고 일시정지하며 라벨을 숨긴다.
- 영상 시간이 **3초 초과**하면 라벨을 표시한다. 라벨은 `fadeIn` 1500ms / `fadeOut` 800ms로 전환되므로, **5~7초 프레임**이 라벨까지 확인하기 좋은 안정 구간이다.
- 화면 전체 선택 전환은 `jackInTheBox` 1500ms를 사용한다. 영상 플레이어는 음소거 상태이며 기본 재생 컨트롤을 숨긴다.
- 원본 코드는 폭을 마운트 시 계산한다. 재현 시 창 크기 변경까지 대응하려면 별도 처리가 필요하다.

## 실시간 데이터와 재현 범위

정적 코드 판독에는 로그인 정보·세션 저장소 조회가 필요하지 않았다. 별도 수집 과정에서 읽기 전용 모니터링 응답을 `data/monitoring-snapshot.json`·`.csv`에 저장했다. 저장 시각은 JSON의 `saved_at`을 기준으로 하며, 총 74행 중 `DRYER_` 태그는 21행이다. 각 행의 `TIMESTAMP`는 센서 데이터 시각으로 파일 저장 시각과 구분한다. 이 스냅샷은 당시 응답 예시이며 이후의 현재 값이나 화면에 표시된 값의 증거로 사용할 수 없다. 아래는 정적 코드에 적힌 연동 위치를 식별하기 위한 기록이다.

- 3층·4층·5~7층은 `selectC101000Monitering_MACHBASE`에서 `jsondata:{}`로 받은 목록 중 `TID`에 `DRYER_`가 들어가는 항목을 사용한다. 최초 마운트 시 로드하고 선택 중 2초 간격으로 갱신한다.
- 항목 필드는 `TID`, `SENSORNM`, `VALUE`, `USL1`, `LSL1`, `TIMESTAMP`다. 숫자는 `Math.abs(Number(VALUE)).toFixed(3)` 후 천 단위 쉼표로 표현한다. 부호가 제거되는 것도 원본 동작이다.
- 계기 컴포넌트에 전달하는 데이터는 `{val, usl, lsl}`이다. 계기 위에 마우스를 올리면 해당 태그의 `TIMESTAMP` 표를 보여 준다.

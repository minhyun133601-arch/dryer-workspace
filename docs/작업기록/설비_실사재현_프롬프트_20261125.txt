3. 검토 결과: 지금 모델이 왜 조잡한가
========================================================================
공통
- 바닥이 밝은 민트색 단색이다. 실제는 광택 있는 진초록 에폭시에 흰 가루 자국, 긁힘, 바랜 얼룩이 있다.
- 벽이 흰 단색이다. 실제는 아이보리 판넬에 가로 이음선, 하부 흰 턱(dado), 바닥에서 올라온 초록 걸레받이.
- 천장이 없다. 실제는 짙은 회색 데크플레이트 + 크림색 H빔 + 케이블트레이 + 둥근 LED등.
- 스테인리스가 회색 플라스틱처럼 보인다. 실제는 거울 같은 반사, 세로 용접 이음선, 가로 이음띠, 녹·갈색 얼룩.
- 설비 주변 공기배관·전선·밸브·안내판이 거의 없다.
- 설비가 가느다란 다리로 서 있다. 실제는 초록 콘크리트 턱(원형·사각) 위에 바로 앉는다.
- 기둥: 사진에는 크림색 H형강, 이음부에 큰 볼트 판(볼트 2열×6), 하부 흰 콘크리트 받침 + 초록 띠.

5층 (사이트) — 가장 심각, 사실상 다시 만들어야 함
- f5-dryer-cone: 다리 4개로 떠 있는 깔때기 → 실제는 챔버 콘이 천장을 뚫고 내려와 바닥의 원형 초록 턱에 앉는다.
- f5-powder-recovery: 작은 콘 3개가 다리 틀에 있음 → 실제는 천장에서 바닥까지 닿는 긴 싸이클론 콘 3개.
- f5-extraction: 초록 모터 두 대 → 실제는 필터상자 달린 송풍기 4세트 + 루츠 블로워 + 큰 송풍기.

4층
- f4-fluid-bed: 매끈한 원통 → 실제 V/F는 높은 철골 데크 위에 있고, 윗면이 둥근 상부와 V자 하부, 난간·계단·진동모터가 있다.
- f4-fine-return, f4-transfer-bin: 사진 어디에도 이 모양이 없다. 사진의 무엇에 해당하는지 확인하고,
  해당 없으면 id는 남기되 카드 02/03에 보이는 실제 이송부 모양으로 바꾼다.

[A] 공통 재질·마감 (가장 먼저, 전 층에 한 번에 효과)
 1) 진초록 에폭시 바닥: 저거칠기 + 절차적 얼룩 텍스처(흰 가루, 긁힘, 타일 모양 바램). 조제·포장 청정실은 하늘색 바닥(카드 05~07·11).
 2) 벽 판넬 가로 이음선, 하부 흰 턱, 초록 걸레받이. 내부 흰 판넬벽은 세로 이음선.
 3) 천장 데크(골 무늬)·크림색 보·배관·케이블트레이는 ceiling 레이어에 넣는다. 평소 자른 보기에서는 안 보이고 사람 보기에서 보인다.
 4) 스테인리스: 브러시 무늬 + 환경 반사(equipment-lighting.js) + 세로·가로 이음선. 일부에 갈색 얼룩.
 5) 기둥 볼트 이음판과 받침. 인스턴싱을 유지한다.
 주의: 매 재질은 장면 등록 재질 규칙을 따른다(여러 재질 배열을 한 메시에 주면 테스트 실패).

   furnace-drawing-model.js / furnace-detail.js 가 이미 있으므로 겹쳐 만들지 말고 사진과 맞는지 비교 후 고친다.

[D] 사이트 7층 (카드 35 보류 2)
 - 챔버 상판: 낮은 원형 단(금속 테) 위 얼룩 있는 넓은 원판과 난간. 가운데 낮은 원통(에어 분배부)에 굵은 둥근 덕트가 부채꼴로 들어감. 작은 송풍기(노란 모터)와 사다리꼴 필터함. 탁자형 노즐 세척대 2개, 검은/노란 호스, 체인 호이스트(빨간 훅). 트러스 지붕과 조명.

[E] 사이트 4층 (카드 3층: 02, 03)
 - 02 V/F: 높이 약 2m 회색 철골 데크 위에 긴 몸체. 윗면은 낮은 곡면, 옆은 직선 판, 아래는 V자로 좁아짐. 난간·계단 2개, 위로 올라가는 배기관 여러 개(보온재 흰 테이프·주름관), 긴 원통 유리창/점검구, 하부에 진동 프레임. 끝쪽 위에 천장에서 내려오는 큰 원뿔(5층 챔버 콘의 하부) + 좁은 연결관 + 주름관.

[F] 사이트 3층 (카드 2층: 17~22)

 - 18 살균기 열교환기: 판형 열교환기 여러 대(볼트·관통봉), "SD 살균기 1호기(HC)" 흰 명판, 은색 보온배관, 파란 레버 밸브.
 - 19 CIP탱크(물), 21 CIP탱크(알칼리), 22 CIP탱크(산): 큰 원통탱크가 철골 데크를 관통. 파란 테두리 명판. 표면에 흘러내린 갈색 자국. 다리 4개, 하부 배관과 펌프. 22 앞에 흰 선풍기. 빨간/흰 출입 금지띠.

[G] 1층 청정실·포장 (카드 04~07, 11~16)
 - 04 외포장기(봉함기): 주황 타공판 큰 덮개(뒷면), 흰 하부함, 앞쪽 검은 레일 2줄에 주황 받침, 조작반 거치대. 초록 바닥.

8. 합격 기준 (스스로 확인하고 보고)
========================================================================
 1) 카드 사진 한 면과 같은 위치·각도로 렌더한 화면을 나란히 놓고, 아래를 보고한다:
    몸체 비율 / 받침 / 색 / 이음선·볼트 / 배관·호스 / 명판. 다른 점이 있으면 숨기지 말고 적는다.
 2) 사진에 있는 설비가 전부 있고, 사진에 없는 조잡한 대체 모양이 남아 있지 않다.
 3) 설비끼리·기둥·벽과 겹치지 않는다(boxes.mjs로 확인).
 4) 사용자 저장배치에서도 옮긴 설비가 안 바뀐다(저장배치 파일 확인이 어려우면 테스트로 대체).
 5) npm test 전부 통과, npm run check 통과. 실패를 줄이려고 테스트 기준을 느슨하게 바꾸지 않는다.
    꼭 바꿔야 하면 이유를 적는다.
 6) 사람 보기(1인칭)에서 5층·6층이 사진과 비슷한 분위기인지 확인한다.
 7) 최종 보고는 한국어로: 어디를 누르면 보이는지 → 무엇을 어떤 사진과 맞췄는지 → 아직 추정인 것.

9. 하지 말 것
========================================================================
 - 사진에 없는 것을 "있을 법해서" 넣지 않는다. 빈 자리는 사진에 있는 것으로만 채운다.
 - 근거를 긴 설명문으로 대신하지 않는다. 모양을 고친다.
 - 이력카드의 옛 사진(2006~2012년)을 최신 사진보다 앞세우지 않는다.
 - 도면 치수와 사진이 다르면 도면을 억지로 따르지 않는다.
 - 개인 이름·연락처를 화면이나 외부로 내보내지 않는다.

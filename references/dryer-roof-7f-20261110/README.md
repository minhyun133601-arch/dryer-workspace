## 엘리베이터 기계실 추가 확인

사용자 확인으로 옥상 계단 옆 방을 엘리베이터 기계실로 구분했다. 60~114초의 1초 간격 접촉시트와 선별 원본 해상도 프레임에서 모터 축단·통풍 커버·큰 홈 바퀴·노란 가드·공통 철골 베이스를 다시 확인했다. 장치의 권상 형식과 정격 사양은 확인하지 못했다.

75초에 보이는 열린 회녹색 양문 제어함과 123초의 천공 양개 출입문은 서로 다르다. 76초에는 별도 벽 부착 단문함과 케이블이 보인다. 80~82초와93/96초의 바닥 고정판·다수 볼트/스프링·로프 또는 케이블 단말 계열 외형은 세부 기능을 미확정으로 남긴다. 제어함 문짝을 방 출입문으로 재사용하거나 고정부를 별도 모터·탱크로 추가하지 않는다. 이 확인은 원본·웹 사진·앱 코드를 변경하지 않는다.


## 전체 공간·설비 보강

A013~A018 전체 시트를 재확인해 1층 43×35m 전체 동, 2층 부분 슬래브와 VOID, 3층 타워·저층 옥상, 4~7층 타워를 구분했다. 공개된 실명·문 개구·낮은 구획벽을 재현하고 용도 미확인 실은 추가하지 않았다. 1층 공장/준비/조제/보일러/공무/보관/사무 구획, 2층 회의·휴게/사진·액자 구획, 3층 콤프레샤실은 각 원도면에서 판독한 명칭이다. OWP의 옛 실명·설비명은 다른 시점의 자료이므로 현재 명칭·위치를 임의 확정하지 않는다.

과거 OWP 3D의 1·3·4층 22개 기존 선택 그룹을 실제 형상과 비교해 다시 만들었다. 5층의 긴 콘3개·외부 구동/배출부4곳, 7층의 관찰 대형 수평관·사각 테이퍼 외함2개를 반영했다. 현재 장거리 배관의 숨은 연결은 확인되지 않아 우회 경로를 임의 추가하지 않았다. 하부 기기 위치와 실별 경계는 도면/공정 관계의 개략 등록이며 현황 실측 결과가 아니다.

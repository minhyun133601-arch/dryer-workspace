### 화면 전환 뒤 깨짐 방지

- 다른 메뉴(작업실의 도면 근거자료 등)로 가면 3D 화면이 숨겨지고 크기가 0이 됩니다. 이때 카메라 비율·맞춤 거리를 1×1로 바꾸지 않고 마지막 크기를 유지합니다.
- 탭을 오래 비우거나 절전한 뒤 브라우저가 WebGL 그래픽 연결을 끊는 경우가 있습니다. 끊기면 그리기를 멈추고, 복구되면 다시 그립니다. 돌아왔는데도 복구되지 않았으면 1.5초 뒤 강제로 복구를 요청합니다.
- 헤드리스 브라우저에서 보일러실·밸브실·조제실·건조실·스틱·소포장·실외기실·액상과 작업실 메뉴를 오가며 확인했습니다. 연결을 일부러 끊었다 복구했을 때 원래 화면과 픽셀이 같았습니다.

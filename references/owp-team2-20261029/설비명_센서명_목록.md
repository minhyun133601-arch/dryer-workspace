# OWP 2팀 설비명·센서명 목록

확인일: 2026-10-29. 근거: `originals/source/video1.js`, `video2.js`, `video3.js`, `video34.js`, `video57.js`와 같은 소스에서 만든 `snapshots/*.html`.

**설비명은 원본 영상 위에 HTML로 덧붙여 표시된다.** 따라서 `images/*.png`의 원본 영상 프레임에는 설비명·계기명이 빠져 있고, `snapshots/floor1.html` 등의 소스 기반 배치 참고에는 이름이 포함되어 있다. 이 목록은 실제 원문 라벨을 구분하여 기록한 것이며 설비 형태나 태그를 보고 새 이름을 추정하지 않았다.

## 2팀 전체

전체 화면의 radio 값은 `1`이며 `video1.js`와 `heechang_0529.webm`을 사용한다. 이 컴포넌트에는 별도의 `.name` 설비명 라벨이 없다. 전체 영상에 그려진 실명·구역명은 영상 자체의 문자이며 개별 설비 이름과 다르다. 실명·구역명을 설비명 목록으로 간주하지 않는다.

## 2팀 1층 — 설비·공정 표시명

아래는 원본 `.name` 텍스트다. 화면에는 17개 라벨이 있으며 `박스`가 두 위치에 표시된다. 센서 태그는 JSX의 상태값 바인딩을 적었고 접미사 `_Value`는 생략했다.

| 원문 설비·공정명 | 위치 클래스 | 함께 표시되는 센서명 | 바인딩 태그 또는 계산 |
| --- | --- | --- | --- |
| ICA1 | `OP-VAL-ICA1` | 전체 수량 / 불량 수량 | `ICA1_Total_Count` / `ICA1_Ng_Count` |
| ICA2 | `OP-VAL-ICA2` | 전체 수량 / 불량 수량 | `ICA2_Total_Count` / `ICA2_Ng_Count` |
| ICA3 | `OP-VAL-ICA3` | 전체 수량 / 불량 수량 | `ICA3_Total_Count` / `ICA3_Ng_Count` |
| XRAY1 | `OP-VAL-XRAY1` | NG수량 | `ICA1_Xray_Ng_Count` |
| XRAY2 | `OP-VAL-XRAY2` | NG수량 | `ICA2_Xray_Ng_Count` |
| XRAY3 | `OP-VAL-XRAY3` | NG수량 | `ICA3_Xray_Ng_Count` |
| 금속검출기 | `OP-VAL-METAL` | NG수량 | `WEIGHT3_Ng_Count` |
| 용해탱크 | `OP-VAL-TANK1` | 온도 / 무게 | `PREPROCESS_Melt_Temp` / `PREPROCESS_Melt_Weight` |
| 혼합B | `OP-VAL-TANK2` | 온도 / 무게 | `PREPROCESS_MixB_Pasteur_Temp` / `PREPROCESS_MixB_Weight` |
| 혼합A | `OP-VAL-TANK3` | 온도 / 무게 | `PREPROCESS_MixA_Pasteur_Temp` / `PREPROCESS_MixA_Weight` |
| 오일탱크 | `OP-VAL-TANK4` | 온도 | `PREPROCESS_MixA_OilTank_Temp` |
| 열수탱크 | `OP-VAL-TANK5` | 온도 | `PREPROCESS_MixB_Pasteur_Temp` |
| S-1 | `OP-VAL-TANK6` | 온도 | `PREPROCESS_MixB_Pasteur_Temp` |
| 지대 | `OP-VAL-WEIGHT1` | 전체수량 | `WEIGHT3_Total_Count` |
| 박스 | `OP-VAL-WEIGHT2` | 전체수량 | `ceil(o / 2)` |
| 박스 | `OP-VAL-WEIGHT3` | 전체수량 | `o` |
| 적재 | `OP-VAL-CONVAYER` | 랩핑 | `o + ceil(o / 2) - 15` |

`o = ICA2_Total_Count + ICA3_Total_Count - ICA3_Xray_Ng_Count`이다. 수량 단위는 `EA`, 온도 단위는 `°C`, 무게에는 별도 단위 라벨이 없다. 열수탱크·S-1이 혼합B 살균온도 태그를 사용하는 것은 원본 바인딩 그대로다.

ICA1~3 라벨은 원본에서 클릭하면 상세 팝업을 연다. `Dialog_List.js`의 팝업은 `ica1.png`에 수치를 덧붙인다. JSX에는 팝업 전용 설비 제목이 별도로 하드코딩되어 있지 않다. 이미지 안의 글자를 데이터의 `SENSORNM`과 자동으로 동일시하지 않는다. 1층 작업표의 `공정명`, `제품명`, `작업자명`은 표 머리글이며 설비명이 아니다.

**균질기**는 원본 팝업의 명시적인 설비명이다. 기본 화면에서는 해당 팝업이 숨겨져 있다.

| --- | --- | --- | --- |
| 균질기(출력값,셋팅값) | 1차 압력 출력값 | `DRYER_E207PV` | bar |

4번 마커는 `detailSensor`, 6번 마커는 `detailSensor1` 표시를 전환한다. 일반 계기에 마우스를 올렸을 때 나타나는 작은 표는 센서 데이터 시각 `TIMESTAMP`이며 추가 설비명이 아니다.

## 데이터 이름의 의미와 참고 파일

- 저장 응답 `data/monitoring-snapshot.json`·`.csv`의 `TID_NM`에는 ICA1·ICA2·ICA3, WEIGHT1·2·3, CONVAYER, PREPROCESS, 건조실 등이 있다. 이는 응답의 그룹명이며 화면의 설비명과 항상 같지 않다.
- `SENSORNM`은 데이터가 가진 측정항목 명칭이다. 위 표처럼 JSX의 고정 라벨과 다른 경우가 있으므로 원문을 나란히 보관했다.
- 데이터는 2026-10-29 14:15:24(한국 시간) 저장 응답이다. 현재 상태를 뜻하지 않는다.
- `data/names.json`은 이 문서의 고정 설비명·계기명 목록을 화면별로 정리한 구조화 자료다. `tag:null`은 단일 태그 대신 계산값을 표시하는 항목이며 `unit:null`은 별도 단위 표기가 없는 항목이다.

현재 저장된 배치 참고는 원본 JSX·CSS를 이용한 오프라인 재현이며 실제 크롬 화면 캡처가 아니다. 원본 영상·소스·저장 응답을 분리하여 보관한다.
